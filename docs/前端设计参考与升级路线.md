# 前端设计参考与升级路线（2026-09 调研）

> 结论先行：**现有 editorial 风格方向是对的，不要推倒重来**。暖白纸张底、墨黑、克制蓝，正好踩在
> 2026 年"反 AI 精致美学"趋势上（行业在刻意追求"人做出来的感觉"：纸张纹理、印刷感、不完美）。
> "简陋感"的真实来源不是配色，而是**组件层完成度**：手写 SVG 图标、无动效、无骨架屏、无 toast、
> 无下拉/对话框原语、表格朴素、没有空状态设计。**补组件层，不换皮肤。**

## 一、现状诊断

| 缺失 | 现状 | 用户感知 |
| --- | --- | --- |
| 组件库 | 全部手写（`Layout.tsx` 的 NavIcon 是逐个手绘 SVG path） | 细节不一致，交互反馈弱 |
| 动效 | 无动画库，仅 CSS transition 140ms | 页面"死"，流式输出无生命感 |
| 加载状态 | 无骨架屏 | 等待 = 白屏或跳动 |
| 反馈系统 | 无 toast/通知中心组件 | 操作结果无回声 |
| 图表 | RagEvalPage/AdminPage 纯文本表格 | 评测数据没有"看板感" |
| 空状态 | 文字占位 | 像半成品 |

已搭好的底子：Tailwind 已接入、ink/accent 自定义色板、prose-chat 排版体系、Qwen 风格引用面板（这个是亮点，保留）。

## 二、推荐体系（与现有 Tailwind 栈兼容性优先）

| 层 | 选型 | 为什么 | 替代项 |
| --- | --- | --- | --- |
| **组件底座** | [shadcn/ui](https://ui.shadcn.com) | copy-paste 模式不锁版本；Tailwind 原生；把现有 ink/accent token 映射进 CSS variables 即可**继承现有 editorial 皮肤**，不会变成 SaaS 模板脸 | Arco/Semi（中文生态好但与 Tailwind 体系冲突，不推荐混用） |
| **AI 聊天** | [assistant-ui](https://www.assistant-ui.com) | 专做 AI 对话：流式、自动滚动（用户上翻时停止跟随）、stop/retry、工具调用可视化；基于 shadcn 设计系统；**支持自定义 runtime 对接自有 SSE 协议**，不强制 Vercel AI SDK | 自研（正在维护的正是这些边角） |
| **图标** | lucide-react | shadcn 标配，替代全部手绘 NavIcon | — |
| **动效** | [Motion](https://motion.dev) + [Origin UI](https://originui.com) + [Magic UI](https://magicui.design) | Origin UI 抄交互细节，Magic UI 抄"标志性瞬间"（流式完成光晕、卡片入场） | — |
| **图表** | [Tremor](https://tremor.so) 或 shadcn charts | RagEvalPage / AdminPage / 面试分数趋势 | Recharts 裸用 |

## 四、分阶段落地

- **Phase 1（地基，1 次改动）**：shadcn/ui CLI 初始化 + token 映射（保留 ink/accent）+ lucide 替换 NavIcon + toast/dialog/skeleton 补齐。纯升级，页面结构不动。
- **Phase 2（ChatPage）**：assistant-ui 重建线程层（流式/滚动/中断/重试），保留自研引用面板与 SSE 解析层（runtime 适配器对接 `streamChat`）。
- **Phase 3（InterviewPage）**：评分报告 artifact 化 + Tremor 雷达图；ResumePage dropzone。
- **Phase 4（管理/评测）**：Tremor 仪表盘块。
- 顺带：Phase 2/3 引入 `React.lazy` 时天然完成路由级代码分割（此前诊断的 25-35KB gzip 收益）。

## 五、不做什么

- 不换 AntD/Arco 整套组件——会跟 Tailwind + 现有 token 体系打架，且丢掉 editorial 个性
- 不上 Aceternity 式炫技动效——与克制的纸张风格冲突，动效只做"反馈"不做"表演"
- 不做暗色模式（`color-scheme: light` 是有意选择，近期不动）
